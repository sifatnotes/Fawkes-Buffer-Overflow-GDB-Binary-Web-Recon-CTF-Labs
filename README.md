## Learning Path

A practical progression is:

1. Start with the **Fawkes Crash Lab 2** and **GDB Lab** to understand program crashes and debugging.
2. Move into the buffer-overflow challenges to build memory-analysis skills.
3. Practice investigating memory behavior with **Memory Maze: Fawkes Overflow**.
4. Explore the binary-focused challenges to strengthen binary-security analysis.
5. Finish with **Fawkes FTP Footprint** and **Fawkes Web Recon 2** for broader reconnaissance practice.

## How to Use the Labs

1. Select a challenge from the collection.
2. Read the lab instructions and identify the intended learning objective.
3. Work exclusively within the authorized CTF environment.
4. Observe program behavior and document relevant findings.
5. Use debugging and analysis tools where the challenge requires them.
6. Record your methodology and explain the security concept demonstrated.
7. Consider appropriate defensive measures for the underlying vulnerability.

Only perform security testing against systems and applications where you have explicit authorization.
